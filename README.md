# Escape Room EDU (MVP)

Standalone frontend per creare e giocare escape room didattiche con enigmi fake.

## Setup

```bash
npm install
```

## Sviluppo locale

```bash
npm run dev
```

Apri `http://localhost:3000`.

## Build produzione

```bash
npm run build
```

## Test

```bash
npm run test
```

## Stampa / Export PDF

- Vai su `/room` e usa il bottone "Esporta PDF".
- Il layout è ottimizzato per A4 (bianco/nero).
